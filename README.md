# Мир легкой атлетики

Веб-приложение на фреймворке Bottle (Python), предназначенное для решения классических задач дискретной математики и теории графов: 
задача коммивояжёра (TSP), задача о минимальном вершинном покрытии, разбиение графа на компоненты сильной связности, задача о рюкзаке на дереве. 
Проект выполнен в рамках учебной практики по специальности 09.02.07 «Информационные системы и программирование».

## Начало работы

Эти инструкции помогут вам запустить копию проекта на вашем локальном компьютере для разработки, тестирования и образовательных целей.

### Необходимые компоненты

Перед началом убедитесь, что у вас установлены следующие программы:

* **Python** (версия 3.8 или выше) - [Скачать Python](https://www.python.org/downloads/)
* **Git** (для клонирования репозитория) - [Скачать Git](https://git-scm.com/downloads)
* **Visual Studio 2022** (рекомендуется) или любой другой редактор кода (VS Code, PyCharm)
* **Любой веб-браузер** (Google Chrome, Firefox, Microsoft Edge, Яндекс Браузер)

### Установка

Пошаговая инструкция по установке и запуску проекта:

**1. Клонируйте репозиторий**

Откройте терминал (командную строку) и выполните команду:
```bash
git clone https://github.com/fckiblessme/BottleWebProject_C326_5_SSCM
```

**2. Перейдите в папку проекта**

```bash
cd BottleWebProject_C326_5_SSCM
```

**3. Создайте виртуальное окружение**
```bash
# Для Windows
python -m venv env

# Для macOs/Linux
python3 -m venv env
```

**4. Активируйте виртуальное окружение**
```bash
# Для Windows
env\Scripts\activate

# Для macOS/Linux
source env/bin/activate
```

**5. Установите зависимости**
```bash
pip install -r requirements.txt
```

**6. Запустите приложение**
```bash
python app.py
```

**7. Откройте сайт в браузере**
Перейдите по адресу: http://localhost:8080

Вы должны увидеть главную страницу с выбором одной из четырёх математических задач.
